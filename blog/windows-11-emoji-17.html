Microsoft Emoji Updates

Windows 11 Now Supports Emoji 17.0

Aug 28, 2026 · 4 min read

Microsoft has started rolling out Emoji 17.0 through a Windows 11 Release Preview update. The same font work is expected to reach the 26H2 feature update later.

What you get

The Windows emoji picker and Segoe UI Emoji font pick up the Emoji 17.0 characters. Existing 3D-style Windows artwork stays, with new items drawn to match that look instead of the flatter Windows 10 style.

  • New faces and objects appear in Win + .
  • Chat apps that use the system font show the new art.
  • Older Windows 10 machines keep the previous font until they are upgraded.

Release Preview first

Insiders on Release Preview can test the font before it is broadly deployed. If a character is still missing, Windows may show a tofu box until the font download finishes. Copying from this site still inserts the correct Unicode.

Microsoft usually follows Unicode by one cycle compared with Android and iOS. Emoji 17.0 on Windows is the catch-up step before Emoji 18.0 designs arrive.
