Privacy Policy

Last updated October 17, 2026

Get Emoji is a static website. It does not have user accounts, a backend database, or first-party analytics scripts in the current build. This page describes what the site itself does in your browser and which third-party hosts may see a request when a page loads.

What this site stores in your browser

If you save favorites or copy emoji, the site writes two localStorage keys on this origin:

  • getemoji.favorites.v1 — emoji you marked as favorites.
  • getemoji.recent.v1 — recently copied emoji (up to 24).

That data stays on your device. It is not uploaded to Get Emoji. Clearing site data, using a private window, or blocking storage will remove or prevent it. If storage is blocked, copying still works; favorites and history will not persist, and a toast explains that.

Clipboard

Copying uses the browser clipboard APIs so you can paste an emoji elsewhere. The site does not read your clipboard contents.

Third-party requests

Pages load images and, for text-to-emoji convert, a public keyword file from these hosts:

  • cdn.jsdelivr.net — Fluent Emoji 3D pictures, Twemoji flag pictures, and the emojilib keyword file.

Those hosts may receive your IP address, user agent, and the requested file as part of ordinary HTTPS. Get Emoji does not control their logs or cookies. If a picture fails to load, the page falls back to the native emoji glyph.

Hosting

The public site is served from GitHub Pages at libraryequipment90-beep.github.io/emoji-hub/. GitHub’s hosting may collect standard server logs as described in GitHub’s own privacy documentation. This project does not add extra tracking pixels.

Cookies and analytics

The current source does not set first-party cookies and does not include Google Analytics, ads, or similar scripts. If analytics is added later, this policy will name the provider, what it collects, and how to opt out before that script is enabled.

Children

The site is a public emoji reference. It does not knowingly collect personal information from children. There is no sign-up form.

Contact

No public contact email is published yet. See contact.html. When an email is added, privacy questions can go there.
